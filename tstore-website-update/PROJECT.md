## ფაილების რუკა

```
index.html              მთავარი გვერდი (CSS პირდაპირ შიგნით წერია)
products/               პროდუქტების გვერდები
  bhrl-13.html            ფლაგმანი
  bhrl-12.html            პროფესიონალური
  bhrl-11.html            ხალხის რჩეული
  bhrl-04.html            სენსორული
  bhrl-10.html            დამალული (მარაგში არაა)
  bhrl-04b.html           დამალული (მარაგში არაა)
  tmy-002.html            დამალული (მარაგში არაა)
assets/product.css      პროდუქტის გვერდების სტილი (ოთხივე იზიარებს)
assets/product.js       შეკვეთის ლოგიკა (ოთხივე იზიარებს) ← ფრთხილად!
functions/api/order.js  Cloudflare Function — შეკვეთას Telegram-ში აგზავნის
images/products/<model>/1.webp
```

⚠️ `assets/product.js` და `assets/product.css` **ყველა პროდუქტის გვერდს ეხება**.
აქ ერთი შეცდომა = ოთხივე გვერდი გატყდა. აქ ცვლილება ცალკე დღეს.
